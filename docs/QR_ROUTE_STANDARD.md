# QR Companion Route Standard

No production QR identifiers are assigned in this revamp.

When approved, use permanent lowercase routes in this form:

- `/card/m365-001/`
- `/card/mbd-001/`
- `/card/hmm-001/`
- `/card/mbb-001/`

Rules:

- Never place personal data in a QR code.
- Keep the printed route permanent and redirect it when companion content moves.
- Publish only approved card text, audio, parent prompts and prayers.
- Test every code at physical print size, on multiple devices and in low light before manufacture.
- Record only the route identifier in analytics.

`card-companion.html` is the reusable no-content foundation until real routes are approved.
