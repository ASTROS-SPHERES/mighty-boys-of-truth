**Status:** Final for the 10-card sample set

### Authoritative placement rule

Use the centre of the map's location marker to determine the grid cell. The two event cards whose discovery locations are not printed as markers on the current base map use dedicated product-map anchors: **The Exodus → Red Sea crossing (F-09)** and **Jesus Calms the Storm → Sea of Galilee (L-06)**.

Each card receives one primary map anchor. A card's wider route belongs to its Journey Trail; it does not receive several competing map codes.

### Production notes

- Mount Sinai remains **H-10**; its printed marker sits in the southward continuation of the map's 10 band.
- David and Bethlehem correctly share **J-08** because both printed location markers fall inside that cell.
- This key supersedes the earlier provisional sample-card codes.
- Do not use the inconsistent example codes embedded in earlier concept mock-ups; this file is the master source for the sample set.
