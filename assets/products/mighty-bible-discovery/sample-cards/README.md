# Mighty Bible Discovery — Ten Sample Card Pairs

This package contains ten separate illustrated card fronts and ten matching information backs for the current map-oriented **Mighty Bible Discovery** product.

## Production specification

- Finished trim size: 80 × 120 mm portrait
- Bleed: 3 mm on every side
- Export canvas: 86 × 126 mm, 1016 × 1488 px at 300 DPI
- Safe, complete navy-and-gold double frame inset from the trim edge
- Product line: **DRAW IT · MAP IT · KNOW IT**
- Card types represented: Bible Hero, Bible Place, Bible Event
- Seven-era map system represented across the ten-card sample
- Scripture appears as references only; no full translation text is reproduced
