# Mighty Bible Discovery — Ten Sample Card Pairs

This directory contains ten illustrated fronts and their ten matching information backs for the current map-oriented **Mighty Bible Discovery** product.

## Production specification

- Finished trim size: 80 × 120 mm portrait
- Bleed: 3 mm on every side
- Export canvas: 86 × 126 mm, 1016 × 1488 px at 300 DPI
- Product line: **DRAW IT · MAP IT · KNOW IT**
- Scripture appears as references only; no full translation text is reproduced
