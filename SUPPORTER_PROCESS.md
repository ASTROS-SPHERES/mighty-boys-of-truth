# Mighty Boys of Truth — Pre-Launch Supporter Process

## Current live flow
1. Visitor joins through the website form.
2. Formspree receives the submission and sends the configured owner notification.
3. The website redirects the supporter to the branded thank-you page.
4. The supporter can return to the site or share the pre-launch page.

## Fields collected
- First name
- Email address
- Country
- Supporter type
- Consent confirmation

## Important free-plan operating rule
Formspree's Free plan stores submission history for a limited period. Treat the email notifications as important records and move to a durable mailing-list/database system before significant launch traffic begins.

## Welcome email
The approved draft is stored in `WELCOME_EMAIL.md`. Automatic Formspree autoresponses require a paid Formspree plan, so use the branded website thank-you page as the immediate free confirmation until a mailing-list platform is connected.

## Before major promotion
- Connect a durable subscriber list platform.
- Enable an automated welcome email.
- Ensure unsubscribe handling is active.
- Preserve consent/source fields when migrating subscribers.
- Test on mobile and desktop before each campaign push.
